## Como funciona

Cada iteração do loop: pega o próximo item de maior prioridade → edita o(s) doc(s) real(is) → marca `- [x]` aqui → remove/reescreve o marcador `> **Pendência:**` na fonte. Antes de declarar concluído, re-executo a auditoria (grep de pendências + revisão deste backlog).

**Legenda de categoria**

| Tag | Significado | Quem decide |
|---|---|---|
| `[RECONCILIAR]` | Duas versões/formulações conflitantes → unificar para a fonte dominante | Eu (reconciliação) |
| `[EXTRAIR]` | Conteúdo existe disperso → formalizar/catalogar (IDs, payloads, fórmulas) | Eu |
| `[CONSISTÊNCIA]` | Cross-ref, âncora, nomenclatura, entidade órfã | Eu |
| `[TUNING]` | Valor numérico de balanceamento → default de 1ª passada, marcado "calibração inicial" | Eu (ratificável) |
| `[DECISÃO]` | Escolha de produto/design genuína → **Série R do ADR, a ratificar** | **Douglas ratifica** |
| `[CONTEÚDO]` | Redação extensa nova (ex.: 42 capítulos do guia) | Eu (esforço à parte) |

Toda `[DECISÃO]` e todo `[TUNING]` fica registrado no ADR (Série R) e sinalizado no resumo da iteração — nada é fabricado em silêncio.
